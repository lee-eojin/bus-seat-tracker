| 문서 | 상태 | 역할 |
|---|---|---|
| [01-proposal.md](01-proposal.md) | 현재 기준 | 기획서. 문제 정의와 수요 검증 |

문서 경로와 절 번호는 코드 주석(`shared/`, `backtest/`)과 CI 요약이 참조한다. 옮기거나 당기려면 참조도 같이 고쳐야 한다.
